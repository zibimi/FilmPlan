# 运行、研究与执行

## 当前扫描

在 skill 目录运行，输出选择本地工作区的新文件：

```bash
python3 scripts/inventory.py --source '/Volumes/分类/合集/要分类' --output '/tmp/film-category-snapshot.json'
```

默认拒绝覆盖输出；每轮使用新文件名。扫描只记录文件大小、mtime、相对路径、扩展名和资源线索，不读影片内容、不判定影片身份。仅查看一级目录以核对规则覆盖，不递归扫描源目录以外的目录。符号链接、隐藏项、回收站及固定排除树不进入清单。若当前请求明确重开固定排除树，需按新范围另做只读扫描，不偷偷绕过脚本。

先检查 complete/errors、挂载、源路径和一级目录差异。目录新增、改名、读取异常时不把旧目录当作有效目标。文件总数不是电影总数，字幕、封面、花絮、分段分别登记。

## 研究与分类

- 根据文件中的中文名、外文名、年份识别作品；父目录只当搜索线索。三者冲突时先核身份，不替文件补造信息。
- 沿用用户偏好的检索顺序：先 Google 搜索，再核豆瓣条目；可补 IMDb、电影节、发行商、电影资料馆等来源。Google 不可用时如实使用可用网页搜索，不能声称查过 Google；豆瓣无法访问则保留限制，不伪造资料。
- 类型标签用于发现候选。读剧情概述与必要评论，解释“什么组织全片”，不能复制标签作为理由。边界、新片、冷门、同名片尤其需要来源。
- 外部事实与目录判断分开：来源支持身份和内容，归属体现用户规则。只读到摘要时不能声称已读全文；搜索无结果不代表影片不存在。
- 对公路尤其检验：移动是否贯穿主要篇幅？人物关键转变是否由沿途事件引起？若去掉旅途结构故事是否仍基本成立？不得按车、火车、旅程等片名关键词分类。
- 每部片给一个主位置，次级标签只写计划。名著改编按已确认优先级；其他多个强匹配先明确理由，真正偏好冲突才询问。
- “已确认规则”与“单片信心”分别记录。建议规则下的高信心候选不能升级为已确认用户偏好；但在本会话“要分类”的 80% 持续授权内，身份明确且置信度达标的条目可计划并执行，无须逐片再次确认。
- 身份已确认但没有主导类别，可建议故事；身份未知、资源关系未明、证据冲突为 research_pending。不得把默认暂留统计成完成核验。

## 固定计划

每次运行写带日期或批次 ID 的 Markdown 与 JSON。相同原路径使用稳定 route_id；原文件移动后通过执行记录对应，不用猜测同名项。计划至少包含：

- 顶层：schema_version、rule_version、规则文件 SHA-256、source_root、snapshot_path、snapshot_sha256、created_at、scan_complete、items。
- 条目：route_id、original_path、source_size、source_mtime_ns、resource_group、media_kind、identity（中文/原名/年份及依据）、proposed_path（未确定为 null）、category、rule_state、reason、alternatives、sources（URL及支持的事实）、confidence、status、authorization。
- status：keep、planned、review_preference、research_pending、related、skip；执行后另记 executed、already_done、conflict、failed，不静默覆盖初始结论。
- authorization 引用本次或本会话的具体授权范围；没有则为 null，不因 skill 存在自动填 approved。

报告首页显示：扫描资源数、确认影片数、建议移动、保留、资料待核、偏好待决、系列/附属资源。列出规则版本、实际来源及未查证部分。给用户的决策清单只列偏好问题；普通检索待办由代理继续完成。

继续 PR 审阅批次时，先读取当前已提交的评论和审阅决定，按片名或稳定 ID 对应；读取反馈不等于获准发送回复或发布更新。

恢复已有批次时先比较实时路径/大小/mtime，分别报告新出现、已消失、已改变。已查证且无变化的条目可复用来源；用户规则更新后重新判断受影响条目。不重复移动，不能仅凭目标同名认定 already_done。

## 执行已授权计划

分类研究本身不移动 NAS。用户要求执行时，准备只消费固定 JSON 的确定性执行器，默认 dry-run，显式执行开关及计划摘要校验；不在执行器里在线查询或临时改分类。

执行前检查：挂载可用、源/目标在授权范围、源大小与 mtime 未变、目标分类确实存在、目标不重名、资源组完整、路径无符号链接或路径穿越。先检查整个批次，冲突条目独立报告。未批准、研究中、偏好未决和暂停系列不得进入可执行集合。

同卷移动使用 no-clobber 操作并检查返回结果；目标出现不覆盖、不删任一副本。跨卷不是本 skill 默认执行范围；用户明确要求时制定复制验证后再清理的单独计划。字幕/分段/花絮必须列出完整 manifest，不能把一个杂合目录整体搬走。

逐项记 intent 与结果；恢复时对照日志和源/目标完整 manifest，无法证明成功则 conflict。完成后读回原位置和新位置、大小及资源清单。出现挂载异常、系统性空读或路径漂移停止该批操作，保留已有日志，不自动重试删除。

去重、改名、删除、转码、发布、导演库迁移均需要各自明确范围，本分类任务不顺带执行。
