# `/Volumes/分类` Routing

Keep naming and category movement in separate plans. Rename first, then move.

1. Check Douban and IMDb genres together.
2. If they agree, use that classification.
3. If they differ, prefer the more specific useful category: comedy over generic drama, romance over comedy when romance is materially central.
4. Example: Douban `剧情 / 悬疑 / 惊悚 / 犯罪` plus IMDb psychological thriller/mystery/thriller routes to `犯罪`.
5. If both only say drama, read plot summaries and reliable criticism. If no specific category is defensible, keep `review`.
6. Chinese-language films and films materially belonging to the Chinese/Chinese-diaspora cultural sphere route to `华语世界`.
7. `/Volumes/分类/合集/要分类` films must be named before moving to a concrete category.

Honor standing daily-scan skips unless the user directly reopens one. A skip is not deletion permission.
