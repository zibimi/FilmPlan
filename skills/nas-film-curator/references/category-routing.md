# `/Volumes/分类` Routing

For classification decisions, use the companion [film-category-rules skill](../../film-category-rules/SKILL.md), or its [English edition](../../film-category-rules/SKILL.en.md), and the user's latest instructions. This reference delegates category policy to that single maintained source.

- Website tags are research clues; the user's narrative, subject, and style criteria determine placement.
- Identity must be established, but filename normalization need not finish before classification. Keep renaming and category moves in separate plans.
- Do not automatically route Chinese-language films into 华语世界. Respect current exclusions and paused series.
- The current inbox task permits direct moves at approximately 80% classification confidence with established identity and successful preflight. This does not authorize whole-library changes, deletion, duplicate replacement, or director-library moves.
- Keep NAS safety checks from this skill: current mount and scope, unchanged sources, complete resource groups, no-clobber operations, logs, and post-move verification.

If the companion skill is unavailable, read it from this repository before classifying; do not revive the superseded tag-based routing rules. Honor explicit skip scopes. A skip is not deletion permission.
