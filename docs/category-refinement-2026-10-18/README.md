# 分类细化审阅入口

请先打开 [分类细化报告](分类细化报告.md)。在 PR 的 Files changed 中，可以直接对电影所在行留评论；每项都有稳定的 route ID，便于把意见回填到计划。

当前为待审核方案：766 个非隐藏直接条目，其中 484 项拟移动、282 项待讨论；另有 4 个隐藏项跳过。部分判断来自已知剧情，未逐片联网复核，报告已标明。

- [分类计划.json](分类计划.json)：固定执行数据、原目标路径及来源清单。
- [执行分类.py](执行分类.py)：默认预演，显式执行参数和匹配摘要才会移动。
- [使用说明](使用说明.md)：修改、重生成报告与中断恢复方式。
- [test_executor.py](test_executor.py)：10 项临时目录测试。

报告和程序属于同一审阅包。创建或合并这个 PR 不代表允许移动 NAS 文件；实际移动仍以之后明确的执行指令为准。只读 NAS 预演及临时目录测试已在本地完成，未移动 NAS 文件。执行时还会重新检查实时挂载、来源变化与目标冲突。

从仓库根目录测试：

```bash
python3 -m unittest discover -s docs/category-refinement-2026-10-18 -p test_executor.py -v
```
